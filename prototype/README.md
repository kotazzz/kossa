# Прототип кассы (веб-симулятор всего стенда)

```bash
cd prototype
python3 serve.py          # http://127.0.0.1:8765/web/index.html (без кэша — модули всегда свежие)
node --test tests/        # 38 автотестов, Node ≥ 20, без зависимостей
```

Без сборки и npm-зависимостей: ES-модули + Canvas. Из сети грузятся только шрифты (fontsource) и
иконки (Lucide) с jsDelivr — это настоящие шаги экрана загрузки.

## Что на экране

- **Дисплей 480×272** (Guition JC4827W543), кадр проходит через RGB565 + яркость подсветки. Без размытия.
- **Клавиатура 4×8** — верхний блок функций и навигации, нижний — цифровой блок (раскладка ниже).
- **Лента чека** — справа, скрывается кнопкой; на узком окне скрыта по умолчанию и открывается поверх; сброс, PNG.
- **Параметры стенда** — выдвижная панель (иконка ползунков): скорость симуляции, питание и UART принтера,
  статистика принтера, лог кадров RP2040 ↔ Guition, загрузка картинок на SD, стирание памяти, сведения об устройстве.

## Раскладка клавиатуры (код = строка×4 + столбец)

| | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 0 | М1 | М2 | М3 | М4 |
| 1 | Код | Возврат | Меню | Аннуляция |
| 2 | − | ↑ | + | Скидка |
| 3 | ← | ↓ | → | Оплата |
| 4 | 7 | 8 | 9 | ⌫ |
| 5 | 4 | 5 | 6 | C |
| 6 | 1 | 2 | 3 | × |
| 7 | 0 | 00 | . | ИТОГ |

Клавиши компьютера: цифры, `.`, Enter = ИТОГ, Backspace = ⌫, Esc = C, стрелки, `+`/`−`, `*` или X = ×,
F1–F4 = М1–М4, K = Код, P = Оплата, D = Скидка, R = Возврат, M = Меню, Delete = Аннуляция.

## Экраны и механики (по мотивам Меркурия-180К)

- **Загрузка**: логотип и полоса по реальным задачам — шрифты, иконки, база из памяти, связь с RP2040 (PING→HELLO),
  принтер (PRINTER_CFG→ACK). Ошибки шагов показываются.
- **Главное меню**: Касса, Отчёты, Деньги, База, Настройки (стрелки + ИТОГ или цифры 1–5; Меню — сюда из любого места).
- **Кассиры** (до 8): при входе в «Кассу» выбирается, кто за кассой (стрелки + ИТОГ или цифра 1–8),
  если активных кассиров больше одного и чек не начат. Кассир и его номер печатаются в чеке.
- **Секции / отделы** (16): состояние «товары / услуги / закрыта», название, налог, ограничение цены.
  Товар из базы продаётся в свою секцию; налог товара важнее налога секции, «Из секции» — брать налог секции.
  В чеке позиции группируются заголовками «СК2 НАПИТКИ», как у Меркурия.
- **Касса**:
  - цена + ИТОГ — свободная позиция в секцию по умолчанию (1); цена + М1/М2 — в секцию 1/2
    (аналог клавиш «1.» и «2.»), цена + М3 — ввод номера секции; закрытая секция и превышение лимита цены — ошибка;
  - `N ×` перед товаром — количество;
  - код + К — точный товар сразу; К без кода или неточный код — живой поиск (точное совпадение первым, затем «123…»);
    в поиске ИТОГ — добавить, × — указать количество; весовой товар всегда спрашивает вес;
  - Скидка: значение, М1 — %, М2 — ₽; «−» переключает на надбавку; скидки/надбавки всегда в конце чека;
  - Возврат: на открытом чеке — выбор позиции/скидки стрелками и удаление; на пустом — номер чека → просмотр →
    полный возврат (печатается документ возврата);
  - Аннуляция — отмена всего открытого чека;
  - Оплата: М1 — наличные, М2 — карта; без суммы — «Уверены?»; карта меньше остатка — предупреждение
    и разделение платежа; наличных меньше остатка — нельзя (сначала картой); больше — сдача до повторного ИТОГ;
  - пустой чек: М1 — копия последнего, М2 — повтор покупки, М3 — прогон ленты, М4 — баланс; `+`/`−` — внесение/выплата.
- **Отчёты**: X, Z (закрытие смены, ГРОСС-ИТОГ), по товарам, почасовой, X/Z по кассирам, X/Z по секциям
  (у них своё гашение и свой ГРОСС-ИТОГ, смену не закрывают — как у Меркурия), баланс кассы, журнал документов.
  У кассиров/секций без продаж печатается только ГРОСС-ИТОГ. Возврат числится за кассиром, который его оформил,
  и за секциями исходного чека.
- **Деньги**: внесение, выплата (нельзя выплатить больше, чем в кассе), баланс.
- **База**: товары (+ добавить, − удалить с подтверждением, ИТОГ — изменить, цифры — поиск; поле «Секция»),
  2 налога (в цене / сверху), название магазина, шапка и подвал чека (многострочные), кассиры (8 мест, «−» — удалить,
  М1 — печать списка), секции (16, М1 — печать реквизитов). Старая база (v1) мигрирует автоматически.
- **Настройки**: нагрев печати, подача после чека, QR на чеке, звук клавиш, яркость, тестовая печать,
  картинки на SD (просмотр и печать с дизерингом), прогон ленты, сброс данных.
- **Ввод текста** (T9, как на старых телефонах): 1–9 и 00 — мультитап; «.» — РУС → ENG → символы → цифры;
  «0» — регистр (один символ → постоянно → выкл); ←/→ — курсор; ⌫ — стереть; ИТОГ — готово; C — отмена.
- **Чек**: название магазина, шапка, № (сквозной), смена, дата, кассир, позиции, скидки/надбавки, ИТОГО, налоги,
  оплаты с получено/сдачей, QR (`KOSSA;N=…;S=…;D=…;M=…`), подвал, «Не является кассовым чеком».

Данные (база, настройки, журнал) хранятся в `localStorage` браузера — это «flash» кассы.

## Архитектура

```
src/common/          ОБЩЕЕ: кадры (COBS+CRC16), сообщения, ESC/POS, растр, QR-кодировщик, распиновка
src/rp2040/          прошивка RP2040 (сканер клавиш + принтер)
src/guition/
  app.js             ядро: линк, очередь печати, стек экранов, загрузка
  pos/               чек, оплаты, журнал/смена/отчёты, контроллер кассовых операций (чистая логика)
  db/                база (товары, налоги, магазин, настройки), поиск
  ui/                примитивы рисования, виджеты, диалоги, ввод чисел и T9
  screens/           экраны: загрузка, меню, касса, отчёты, база, настройки
  print/layout.js    вёрстка чеков и отчётов
  receipt.js         построитель страницы 384 px (текст ячейками 12 px, картинки, QR)
src/sim/             СИМУЛЯТОРЫ железа: UART, GPIO, матрица, принтер
src/world.js         сборка: прошивки + симуляторы
web/                 браузерные HAL и панель
tests/               логика (pos), система (system), сценарии кассы через клавиатуру (cash)
```

| HAL в прототипе | На железе |
|---|---|
| `gpio.*`, `UartPort.*`, `millis()` | Arduino-Pico / ESP32 `Serial*`, GPIO, `millis()` |
| `createSurface` (подмножество Canvas2D) + `Gfx` | LVGL / Arduino_GFX |
| `display.present`, `setBrightness` | NV3041A по QSPI, PWM подсветки (IO1) |
| `storage.load/save` | LittleFS / SD |
| `assets.loadFonts/loadIcons`, `icons.draw` | шрифты и иконки, собранные в прошивку (LVGL font/image converter) |
| `beep` | динамик через I2S |
| `sd.list/loadImage` | SD_MMC + декодер PNG/JPEG |

Чистая логика (`src/common`, `src/guition/pos`, `db`, `ui/t9.js`) переносится на C/C++ по тестам из `tests/`.
QR-кодировщик написан с нуля (byte mode, уровень M, версии 1–10), проверен декодером браузера.

## Упрощения / не проверено на железе

- Полярность DTR, буфер и пороги принтера; набор команд ESC/POS ограничен (`src/sim/printer.js`).
- Встроенный шрифт принтера и UI-шрифты рисуются Canvas (на железе — битмап 12×24 и LVGL-шрифты).
- Скорость отрисовки ESP32-S3 не моделируется. Пароли кассиров и режимов — позже; отчёт по услугам отдельно не выделен.
