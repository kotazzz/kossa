# kossa — самодельная нефискальная касса (ЧПМ)

Контекст проекта, собранный 2026-10-26. Цель: собрать нефискальную кассу с
экраном, клавиатурой и термопринтером. Железо должно легко перепрофилироваться
(принтер картинок, игрушка) — всё программируется целиком.

## Архитектура (решено)

```
[2× мембранная 4×4] ──12 проводов──► [RP2040-Zero] ◄── UART 3,3 В ──► [Guition JC4827W543]
                                          │                           (ESP32-S3, экран 480×272,
                                          └── TTL UART + DTR ──► [принтер QR701 TTL]   логика кассы, LVGL)
```

- **Guition JC4827W543** — мозг кассы и экран. Рисует UI, считает, формирует чек.
- **RP2040-Zero** — контроллер периферии: сканирует клавиши, кормит принтер с
  учётом DTR (busy). Нужен, потому что у Guition наружу выведено только 10 GPIO.
- **Принтер QR701 (TTL)** — 58 мм, 203 dpi, 384 точки/строка, ESC/POS, 5–9 В.
- **Клавиатуры** — две мембранные 4×4 (32 клавиши, общие столбцы).

## Статус

- Железо выбрано, ничего не заказано (на момент записи).
- Питание (блок принтера 5–9 В/2,5 А, батарея, зарядка) — обсуждение отложено.
- Корпус, лоток рулона, отрывная кромка — на 3D-принтере, отложено.
- Прототип-симулятор (`prototype/`): касса по мотивам Меркурия-180К — меню режимов, продажи, оплаты, возвраты, X/Z-отчёты, база товаров, T9-ввод, чек с QR.
- Прошивка на железе не начата; прототип — эталон для неё.

## Важное

- Всё, что помечено «не проверено» — вывод из чужих документов или объявлений, а не
  измерение на железе. Первым делом проверить на живых платах (см. docs/07).
