## Документация

- Guition JC4827W543 (репозиторий с примерами, таблицей пинов, заводской прошивкой):
  https://github.com/profi-max/JC4827W543_4.3inch_ESP32S3_board
  - Таблица пинов: `Docs/4.3 inches IO pin distribution.xls/.pdf`
  - Фото платы с разъёмами: `Pictures/1-2.png`
  - Загрузки производителя: http://www.jczn1688.com/zlxz
- Waveshare ESP32-S3-Touch-LCD-4.3 (для сравнения): https://docs.waveshare.com/ESP32-S3-Touch-LCD-4.3
- QR701: примеры/руководства (сторонние):
  - https://github.com/Nirmata-Labs/QR701-RS232-Thermal-Printer
  - https://github.com/rdiot/rdiot-s221 (pinout: GND, RX, TX, DTR, VH)
  - https://manuals.plus/asin/B0867B6SJM (Goojprt QR701 manual)
  - https://leap.tardate.com/playground/thermalprinter/qr701basics/ (не открылся в сессии)
- Библиотеки: Arduino_GFX (https://github.com/moononournation/Arduino_GFX), LVGL 8.4.0
  (https://github.com/lvgl/lvgl/releases/tag/v8.4.0), TouchLib (https://github.com/mmMicky/TouchLib),
  Adafruit_Thermal (совместимая с QR701 по мнению сообщества).
