# Распиновки и подключение

## Guition JC4827W543 (источник: profi-max/JC4827W543_4.3inch_ESP32S3_board, Docs/ и Pictures/1-2.png)

Свободные GPIO (10 штук) выведены на JST 1.25:

| Разъём | Контакты |
|---|---|
| P2 | IO46, IO9, IO14, IO5 |
| P3 | IO6, IO7, IO15, IO16 |
| P4 | GND, 3,3 В, IO17 (U1TXD), IO18 (U1RXD) — подпись UART1 |
| P5 | GND, 3,3 В, IO17, IO18 — тот же UART1, белый разъём |

**Расхождение:** карточка AliExpress пишет «+5V, TX, RX, GND»; на фото платы у P4/P5 — 3,3 В.
Измерить мультиметром до подключения.

Занятые пины:

| Функция | Пины |
|---|---|
| Экран QSPI (NV3041A) | CS 45, SCK 47, D0 21, D1 48, D2 40, D3 39 |
| Подсветка | IO1 (PWM) |
| Тач GT911 (I2C) | SCL 4, SDA 8, INT 3, RST 38 |
| Резистивный тач (если версия R) | CLK 12, MISO 13, MOSI 11, CS 38, INT 3 |
| microSD (SPI, общая с резистивным тачем) | CS 10, CLK 12, IO11 = MISO, IO13 = MOSI по xls производителя; в README репо наоборот (MISO 13, MOSI 11) — сверить по рабочему примеру |
| Динамик (I2S) | LRCLK 2, DIN 41, BCLK 42 |
| USB | IO19 (D+), IO20 (D−) |
| UART0 (прошивка/лог) | IO43 TX, IO44 RX |
| Boot | IO0 |

Заметки:
- IO46 — strapping-пин ESP32-S3; не вешать на сигнал, который может быть высоким при старте.
- IO17/IO18 свободны для связи с RP2040.
- Питание модуля: 5 В по USB-C.

## Принтер QR701 TTL (источник: сторонние руководства JP-QR701, не продавца — сверить по шелкографии)

Пять контактов: **GND, RX, TX, DTR, VH**.

| Пин | Что |
|---|---|
| VH | Питание принтера 5–9 В (до ~2,5 А) |
| GND | Общий |
| RX | Вход данных в принтер |
| TX | Выход принтера (статус) |
| DTR | Выход «занят» (аналог CTS на стороне хоста) — полярность сверить |

Не проверено: уровень логики принтера (3,3 В или 5 В), скорость по умолчанию (9600 или 19200).
Узнать: включить принтер с зажатой кнопкой подачи — печатается страница самотеста с настройками.
Если TX/DTR принтера дают 5 В — делитель 1 кОм + 2 кОм (≈3,3 В) на входе RP2040.

## RP2040-Zero (предложение распиновки)

Edge-пины: GP0–GP15, GP26–GP29 + 5V, GND, 3V3. Логика 3,3 В.

| Назначение | Пины RP2040-Zero |
|---|---|
| UART0 ↔ Guition | GP0 (TX) → IO18 Guition (RX); GP1 (RX) ← IO17 Guition (TX); GND |
| UART1 ↔ принтер | GP4 (TX) → RX принтера; GP5 (RX) ← TX принтера (делитель при 5 В) |
| DTR принтера | GP6 (вход) |
| Строки клавиатур | GP8–GP15 (8 штук: A=GP8–11, B=GP12–15) |
| Столбцы (общие) | GP26–GP29 (4 штуки) |
| Питание | 5 V (VBUS) от общего 5 В; **не** от 3,3 В Guition |

Клавиатура 4×4 мембранная: 8-контактный шлейф, шаг 2,54 мм; обычно первые 4 контакта —
строки, последние 4 — столбцы (проверить прозвонкой). Диодов нет; одновременные нажатия
нескольких клавиш дают «призраки» — для кассы допустимо.

Скан: каждую строку по очереди выставить в LOW (остальные Hi-Z), читать столбцы с pull-up.
Две клавиатуры: столбцы соединены параллельно, строки раздельны → логическая матрица 8×4 = 32 клавиши.
Код клавиши = row*4 + col (0..31). Назначение клавиш (раскладка накладки) — prototype/README.md и src/guition/keymap.js.

## Питание (ЧЕРНОВИК, отложено)

- Guition: 5 В/≈0,3 А (USB-C).
- RP2040: 5 В/<0,1 А.
- Принтер: 5–9 В, пик до 2,5 А. Нельзя питать от ESP/RP2040.
- Идея: 2S Li-ion (7,4 В) напрямую на VH принтера + понижающий преобразователь на 5 В для остального.
- Земли всех блоков должны быть общими.
