# Тестовая среда (предложение): писать прошивку до прихода железа

Идея: каждый уровень (UI, протокол, принтер, клавиши) тестируется на хосте, без платы.

## 1. Схема «хост ↔ симуляторы»

```
 Guition-прошивка (логика кассы)           RP2040-прошивка
        │  UART-кадры (см. 04)                    │ матрица 8×4 + принтерный UART
        ▼                                         ▼
  виртуальный порт ───────────────►  симулятор RP2040 (Python)
  (pty / socat / loopback)                  ├─ эмуляция клавиш (скрипт / клавиатура ПК)
                                            └─ эмулятор ESC/POS → PNG (что напечатано)
```

## 2. Что собрать

1. **Библиотека кадров (C++/C, общая)** — COBS + CRC16 + разбор сообщений (04-link-protocol.md).
   Один исходник для Guition, RP2040 и хост-тестов (Catch2/Unity/GoogleTest).
2. **Симулятор принтера (Python)** — принимает байты ESC/POS, поддерживает `ESC @`, `ESC a`, `GS v 0`,
   `LF`, `ESC d`, режим DTR (имитация busy), выдаёт PNG ленты 384 px шириной. Пригодится и на железе: сравнивать вывод.
3. **Симулятор RP2040 (Python)** — читает UART-кадры, превращает PRINT_* в вызовы принтерного симулятора,
   генерирует KEY (из файла скрипта или с клавиатуры хоста).
4. **UI на ПК** — LVGL + SDL (lv_port_pc_vscode, или PlatformIO native). Разрешение 480×272 как у Guition.
   Тач → мышь. Шрифты и картинки те же, что в прошивке.
5. **Юнит-тесты логики кассы** — отдельно от железа: корзина, суммы, формирование чека, сериализация.
6. **Тест растра** — набор тестовых картинок (шахматка, градиент, QR, кириллица) → дизеринг → эталонные PNG.

## 3. Порядок работ

1. Определить формат кадров, написать общую библиотеку + тесты (фаззинг CRC/COBS).
2. Симулятор принтера + рендер чека (кириллица → растр → ESC/POS).
3. Симулятор RP2040 и тест «клавиша → событие на Guition».
4. UI в LVGL-SDL, затем портирование на Guition (Arduino_GFX).
5. Железо: принтер отдельно (самотест, шахматка), затем RP2040, затем интеграция.

## 4. Инструменты

- PlatformIO (одна среда для Arduino-ESP32, Arduino-Pico и native-тестов).
- Python 3.11+: `pyserial`, `Pillow` (рендер ленты), `pytest`, `socat` (виртуальный COM).
- LVGL 8.4.0 (совпадает с версией для Guition).
- RP2040: Arduino-Pico (Earle Philhower) либо pico-sdk; UF2-прошивка перетаскиванием.
- Guition: Arduino_GFX 1.4.6, TouchLib, LVGL 8.4.0.

## 5. Эталонные данные для тестов

- Размер ленты: 384 px ширина, 1 бит; байт = 8 точек, бит 7 слева, 1 = чёрный.
- Размер экрана: 480×272, RGB565.
- Клавиши: код = row*4 + col, 0..31 (два 4×4, общие столбцы).
- Кадр: COBS( TYPE | SEQ | LEN16 | PAYLOAD | CRC16 ) + 0x00, макс. payload 512.
