# Протокол принтера: ESC/POS по TTL UART

QR701 — стандартный «встраиваемый» термопринтер: асинхронный последовательный порт
**8N1**, команды **ESC/POS** (Epson-подобные). Скорость по умолчанию 9600 или 19200 (не проверено,
см. самотест). Никакого «драйвера» нет — просто байты в UART.

## Скорость и объём данных

- Строка 384 точки = **48 байт**. 203 dpi = 8 точек/мм.
- При 9600 бод ≈ 960 Б/с ≈ 20 строк/с ≈ 2,5 мм/с — картинки печатаются мучительно медленно.
- Для 60 мм/с нужно ≈ 480 строк/с ≈ 23 КБ/с ≈ 230 кбод; практический предел определяет нагрев (питание/плотность).
- Цель: поднять скорость принтера до 115200 (≈ 30 мм/с) или выше. Способ смены скорости у конкретной
  партии **не проверен**: смотреть самотест (удержание кнопки подачи при включении) и документацию продавца.

## Управление потоком

- Буфер принтера маленький. Растр нужно подавать порциями и ждать линию **DTR** (busy) — по ней принтер
  сообщает, что не готов. Полярность проверить осциллографом/мультиметром.
- Если DTR недоступен — подавать с паузами (приблизительно по скорости печати) или опрашивать статус.
- Запасной вариант: команда статуса реального времени `DLE EOT n` (`10 04 n`), если TX принтера подключён.

## Основные команды (стандарт ESC/POS; поддержку на конкретной партии проверить)

| Действие | Байты |
|---|---|
| Инициализация | `1B 40` (ESC @) |
| Перевод строки | `0A` |
| Подача бумаги на n строк | `1B 64 n` (ESC d n) |
| Подача на n точек | `1B 4A n` (ESC J n) |
| Выравнивание: 0 лев, 1 центр, 2 прав | `1B 61 n` (ESC a n) |
| Жирный вкл/выкл | `1B 45 n` (ESC E n) |
| Подчёркивание | `1B 2D n` (ESC - n) |
| Размер символа (x2 и т. д.) | `1D 21 n` (GS ! n) |
| Инверсия | `1D 42 n` (GS B n) |
| Кодовая страница | `1B 74 n` (ESC t n) |
| Параметры нагрева | `1B 37 n1 n2 n3` (ESC 7), в Adafruit-стиле ещё плотность `12 23 n` (DC2 # n) |
| Штрих-код | `1D 6B ...` (GS k) |
| Растровая картинка | `1D 76 30 m xL xH yL yH d...` (GS v 0), см. ниже |

## Растр: GS v 0

```
1D 76 30 m xL xH yL yH  d1 ... dk
```

- `m` = 0 (нормальная плотность), 1 (×2 по горизонтали), 2 (×2 по вертикали), 3 (×2 обе).
- `xL xH` — ширина в **байтах** (little-endian): для 384 точек = 48 → `30 00`.
- `yL yH` — высота в точках (строках): например 100 строк → `64 00`.
- Данные: `k = ширина_в_байтах × высота`. Бит 7 байта — самая левая точка; **1 = чёрная точка**.
- Старый метод: `ESC * m nL nH d...` (24-точечные колонки) — медленнее, поддержка хуже.
- Некоторые клоны используют `DC2 *` (`12 2A rows bytes`) — именно так работает библиотека Adafruit_Thermal.
  QR701 известен как совместимый с Adafruit_Thermal (RDIoT S221 и др. примеры) — fallback.
- Большие картинки лучше резать на полосы по 24–64 строки и между ними ждать DTR.

## Что печатать нельзя / ограничения

- **Кириллица:** во встроенных шрифтах QR701 только ASCII и GB2312 (по описанию). Кодовые страницы CP866/CP1251
  в QR701 **не заявлены**. Решение: рендерить весь текст в растр на ESP32 (шрифт + LVGL/Arduino_GFX/собственный рендерер).
- Цвет невозможен: только 1-битный растр. Полутона — через дизеринг (Floyd–Steinberg/Bayer).
- QR/штрих-код: аппаратные команды (`GS ( k`, `GS k`) на мини-принтерах часто не реализованы —
  генерировать QR на ESP32 (библиотека qrcode) и печатать как растр.
- Ширина: 384 точки (48 мм) на строку; картинки шире надо уменьшать.
- Обрезчика нет: бумагу отрывают рукой по зубцу (лоток и зубец печатаются/гнутся отдельно).
- Качество зависит от питания: 5 В → бледно, 9 В → норма. Пиковые токи до ~2,5 А.

## План проверки на железе (по порядку)

1. Самотест: удерживать кнопку подачи при включении → скорость, кодировка, версия.
2. Подать 5–9 В, соединить GND, отправить `ESC @` и `Hello\n` на известной скорости.
3. Растр 384×64 (шахматка) через `GS v 0`; если не печатает — попробовать `DC2 *`.
4. Замерить уровни TX/DTR (3,3 или 5 В) и полярность DTR.
5. Найти и зафиксировать рабочую скорость, ESC 7 параметры нагрева.
